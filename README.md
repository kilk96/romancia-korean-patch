# 로맨시아 MSX2 한글화 패치

MSX2용 《로맨시아》 일본판의 게임 대사를 한국어로 즐기실 수 있도록 만든 비공식·비상업 팬 번역 패치입니다. 원본 게임 파일과 패치가 적용된 게임 파일은 제공하지 않습니다.

## 다운로드

[최신 GitHub Release](../../releases/latest)에서 다음 두 파일 중 하나를 받아 주세요.

- `romancia-ko-v1.0.zip`: IPS 형식
- `romancia-ko-v1.0-xdelta.zip`: xdelta 형식

두 형식은 같은 한글판 결과를 만듭니다. 익숙한 패치 도구에서 지원하는 형식을 선택하시고, ZIP 안의 README에 따라 적용해 주세요.

GitHub가 자동으로 제공하는 `Source code.zip`은 한글화 패치가 아니므로 받지 않으셔도 됩니다.

## 필요한 원본

합법적으로 보유하신 일본판 MSX2 ROM을 준비해 주세요. 파일명은 ROM을 정리한 목록이나 보관 방식에 따라 다를 수 있으므로, 이름보다 아래의 파일 크기와 SHA-256 값이 일치하는지 확인해 주세요.

- No-Intro 표기명: `Dragon Slayer Jr. - Romancia (Japan).rom`
- 다른 표기 예: `Romancia (Japan).rom`
- 파일 크기: 131,072바이트
- SHA-256: `097060b1c8d6b0728e8bfc9dc726389cf439515845e3686aade2f7e6403f3cb6`

SHA-256은 원본 파일이 이 패치에서 지원하는 판본인지 확인하는 값입니다.

No-Intro는 ROM 파일을 배포하는 곳이 아니라, 게임 이미지의 이름·크기·해시를 정리해 같은 판본인지 식별할 수 있게 하는 데이터베이스 프로젝트입니다.

## 번역 및 확인 범위

- 게임에서 대화로 표시되는 문장 157개를 한국어로 번역했습니다.
- 용사편을 끝까지 진행하며 확인했고, 공주 세리나편도 주요 진행 장면을 확인했습니다.
- 확인 과정에서 문장이 중간부터 표시되던 문제를 수정하고 다시 확인했습니다.
- 타이틀 화면, 비밀번호 화면, 일부 메뉴와 시스템 문구는 번역되지 않았습니다.
- 플레이 중 만나지 못한 모든 조건별 장면과 실제 MSX 기기에서의 장시간 실행은 확인하지 못했습니다.

## 문제 제보

문제가 발생하면 사용하신 패치 형식, 에뮬레이터 이름, 문제가 나타난 장면과 문장을 알려 주세요. 가능하면 화면 캡처도 함께 올려 주시면 확인에 도움이 됩니다.

원본 게임 파일이나 패치가 적용된 게임 파일은 첨부하지 말아 주세요.

## 안내

본 패치는 원작사와 관계없이 제작된 팬 번역입니다. 상업적으로 이용하거나 원본·패치 적용 완료 게임 파일을 재배포하지 말아 주세요.
