# 로맨시아 — MSX2 한글 패치

MSX2 일본판 《로맨시아》의 게임 대사를 한국어로 즐기실 수 있는 비공식 팬 번역 패치입니다. 현재 배포 버전은 **v1.0.0**이며, 패치 파일명에는 `v1.0`으로 표기되어 있습니다.

## 다운로드

[최신 패치 다운로드](https://github.com/kilk96/romancia-korean-patch/releases/latest)의 **Assets**(첨부 파일)에서 다음 중 하나를 받아 압축을 풀어 주세요.

| 파일 | 적용 도구 |
|---|---|
| `romancia-ko-v1.0.zip` | IPS 지원 도구(예: Flips) |
| `romancia-ko-v1.0-xdelta.zip` | xdelta 3.2 이상 지원 도구 |

두 형식은 같은 한글판을 만듭니다. 한 가지만 적용해 주세요. 원본 게임 파일은 별도로 준비해야 하며, GitHub의 `Source code` 압축 파일은 받지 않으셔도 됩니다.

## 적용 방법

1. 보유하신 일본판 MSX2 원본 ROM을 복사하고, 아래 **지원 원본과 파일 확인**의 크기와 SHA-256이 일치하는지 확인해 주세요. 특히 IPS는 다른 원본에도 적용될 수 있어 이 확인이 필요합니다.
2. 받은 형식에 맞는 도구에서 `romancia-ko-v1.0.ips` 또는 `romancia-ko-v1.0.xdelta`와 원본 ROM을 선택해 주세요. xdelta판은 **3.2 이상**을 지원해야 합니다.
3. 결과를 `Romancia Korean v1.0.rom`처럼 원본과 다른 이름으로 저장해 주세요. 이전 한글판을 사용하셨어도 패치는 일본판 원본에 적용해 주세요.
4. 결과 파일의 크기와 SHA-256을 확인한 뒤 MSX2 에뮬레이터에서 실행해 주세요.

## 번역·확인 범위

- 게임 대사 157개를 한국어로 번역했습니다.
- 용사편을 끝까지 진행하며 확인했고, 공주 세리나편도 주요 진행 장면을 확인했습니다.
- 문장이 중간부터 표시되던 문제를 수정하고 해당 장면을 다시 확인했습니다.

## 실행과 저장

에뮬레이터가 게임을 자동 인식하지 못하면 카트리지 매퍼(게임 데이터를 읽는 방식)를 **ASCII16**으로 설정해 주세요. 기존에 사용하던 저장 파일은 별도로 백업해 주세요.

## 알려진 제한

- 타이틀 화면, 비밀번호 화면, 일부 메뉴와 시스템 문구는 원문을 유지합니다.
- 플레이 중 만나지 못한 모든 조건별 장면과 실제 MSX 기기에서의 장시간 실행은 확인하지 못했습니다.

## 지원 원본과 파일 확인

파일명은 보관 방식이나 목록에 따라 달라질 수 있습니다. 아래 크기와 SHA-256으로 지원 판본을 확인해 주세요. SHA-256은 파일 내용이 같은지 확인하는 값입니다.

| 항목 | 값 |
|---|---|
| 지원 원본 | 로맨시아 일본판, MSX2 |
| 파일명 예시 | `Dragon Slayer Jr. - Romancia (Japan).rom` 또는 `Romancia (Japan).rom` |
| 원본 크기 | 131,072바이트 |
| 원본 SHA-256 | `097060b1c8d6b0728e8bfc9dc726389cf439515845e3686aade2f7e6403f3cb6` |
| 적용 결과 크기 | 262,144바이트 |
| 적용 결과 SHA-256 | `91758f8db7c436803f790b9912b3471f26be77df42b99ef2d19c81624d1135bd` |

첫 번째 파일명은 No-Intro의 표기 예입니다. No-Intro는 게임 이미지의 이름·크기·해시를 정리하는 데이터베이스 프로젝트입니다.

Windows PowerShell에서 다음 명령의 파일명을 실제 파일명으로 바꾸면 SHA-256을 확인할 수 있습니다.

```powershell
Get-FileHash "Romancia (Japan).rom" -Algorithm SHA256
```
